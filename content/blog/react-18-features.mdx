# React 18 新特性深度解析

React 18 是 React 历史上最重要的版本之一，引入了期待已久的**并发特性**。本文将深入分析这些新特性及其实际应用。

## 并发渲染（Concurrent Rendering）

并发渲染是 React 18 的核心特性，它允许 React 同时准备多个版本的 UI。

### 什么是并发？

在传统的同步渲染中，一旦开始渲染，就必须完成整个组件树的渲染才能响应用户输入。并发渲染则允许 React：

- **中断**正在进行的渲染
- **暂停**低优先级更新
- **复用**之前的工作

```tsx
// React 18 之前：同步渲染
// 渲染 → 渲染 → 渲染 → 用户交互被阻塞

// React 18：并发渲染
// 渲染 → 中断 → 响应用户 → 恢复渲染
```

## 自动批处理（Automatic Batching）

### React 17 的问题

在 React 17 中，只有在 React 事件处理函数中的多次状态更新会被批处理：

```tsx
// React 17
function handleClick() {
  setCount(c => c + 1); // 不会立即重新渲染
  setFlag(f => !f);     // 不会立即重新渲染
  // React 会将这两次更新合并为一次重新渲染
}

// 但是在 setTimeout、Promise、原生事件中：
setTimeout(() => {
  setCount(c => c + 1); // 重新渲染
  setFlag(f => !f);     // 又重新渲染（两次渲染！）
}, 1000);
```

### React 18 的改进

React 18 自动将所有状态更新进行批处理：

```tsx
// React 18 - 所有情况都会自动批处理
setTimeout(() => {
  setCount(c => c + 1);
  setFlag(f => !f);
  // 只会重新渲染一次！
}, 1000);

// 同样适用于 Promise
fetch('/api/data').then(() => {
  setData(newData);
  setLoading(false);
  // 只会重新渲染一次！
});
```

### 退出批处理

如果你确实需要立即更新，可以使用 `flushSync`：

```tsx
import { flushSync } from 'react-dom';

function handleClick() {
  flushSync(() => {
    setCount(c => c + 1);
  });
  // DOM 已更新
  
  flushSync(() => {
    setFlag(f => !f);
  });
  // DOM 再次更新
}
```

## Transitions API

Transitions 允许你将某些更新标记为"过渡"，告诉 React 它们是非紧急的。

### useTransition Hook

```tsx
import { useState, useTransition } from 'react';

function SearchResults() {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState([]);
  const [isPending, startTransition] = useTransition();

  function handleChange(e) {
    // 紧急更新：更新输入框
    setQuery(e.target.value);
    
    // 过渡更新：更新搜索结果
    startTransition(() => {
      setResults(searchDatabase(e.target.value));
    });
  }

  return (
    <div>
      <input value={query} onChange={handleChange} />
      {isPending ? (
        <div>加载中...</div>
      ) : (
        <ResultsList results={results} />
      )}
    </div>
  );
}
```

### useDeferredValue Hook

另一种延迟非紧急更新的方式：

```tsx
import { useState, useDeferredValue } from 'react';

function SearchResults() {
  const [query, setQuery] = useState('');
  const deferredQuery = useDeferredValue(query);
  
  return (
    <div>
      <input 
        value={query} 
        onChange={e => setQuery(e.target.value)} 
      />
      {/* 使用延迟的值进行渲染 */}
      <ResultsList query={deferredQuery} />
    </div>
  );
}
```

## Suspense 改进

React 18 增强了 Suspense 的功能，支持服务端渲染。

### 基本用法

```tsx
import { Suspense } from 'react';

function App() {
  return (
    <Suspense fallback={<Spinner />}>
      <Comments />
    </Suspense>
  );
}
```

### 嵌套 Suspense

```tsx
<Suspense fallback={<PageSkeleton />}>
  <Header />
  <Suspense fallback={<SidebarSkeleton />}>
    <Sidebar />
  </Suspense>
  <Content />
</Suspense>
```

## 新的 Hooks

### useId

生成稳定的唯一 ID，支持服务端渲染：

```tsx
import { useId } from 'react';

function FormField({ label }) {
  const id = useId();
  return (
    <div>
      <label htmlFor={id}>{label}</label>
      <input id={id} type="text" />
    </div>
  );
}
```

### useSyncExternalStore

订阅外部数据源的推荐方式：

```tsx
import { useSyncExternalStore } from 'react';

function useOnlineStatus() {
  return useSyncExternalStore(
    subscribe,
    () => navigator.onLine,
    () => true // 服务端渲染时的值
  );
}
```

## 升级指南

### 1. 更新 ReactDOM.render

```tsx
// React 17
import ReactDOM from 'react-dom';
ReactDOM.render(<App />, document.getElementById('root'));

// React 18
import { createRoot } from 'react-dom/client';
const root = createRoot(document.getElementById('root'));
root.render(<App />);
```

### 2. 启用严格模式

```tsx
<React.StrictMode>
  <App />
</React.StrictMode>
```

## 总结

React 18 的核心改进：

| 特性 | 描述 |
|-----|------|
| 并发渲染 | 可中断的渲染过程 |
| 自动批处理 | 减少不必要的重新渲染 |
| Transitions | 区分紧急和非紧急更新 |
| Suspense SSR | 流式服务端渲染 |
| 新 Hooks | useId、useSyncExternalStore 等 |

这些特性为构建更流畅、响应更快的用户界面提供了强大的工具。
